Bowtie2 / BWA — Short-Read Aligners

Fast NGS read alignment to reference genomes. Bowtie2 for DNA-seq; BWA-MEM for long reads. Run via Galaxy.

Galaxy Platform ↗
Powered by Galaxy Platform

How to run Bowtie2 / BWA on Galaxy:

  1. Go to usegalaxy.org (free account)
  2. Upload your FASTQ reads (History → Upload)
  3. Search "Bowtie2" or "BWA-MEM" in the Tool panel
  4. Select reference genome (e.g., hg38, mm10)
  5. Set parameters and click Execute
  6. Download BAM/SAM output for downstream analysis

HISAT2 / STAR — RNA-seq Aligners

Splice-aware aligners for mapping RNA-seq reads to reference genomes. HISAT2 is faster; STAR is more accurate for junction detection.

Run on Galaxy ↗
⚙️ Software Tool — Run via Galaxy

HISAT2:

  • Fast splice-aware alignment
  • Low memory (4GB index for hg38)
  • Best for standard RNA-seq
  • Outputs BAM for downstream use

STAR:

  • Ultra-fast alignment (50M reads/hr)
  • High memory (~32GB for hg38)
  • Best junction accuracy
  • Supports fusion gene detection

FeatureCounts / Salmon — Read Quantification

Count reads per gene (FeatureCounts) or quantify transcript abundances with quasi-mapping (Salmon).

Run on Galaxy ↗
⚙️ Software Tool — Run via Galaxy

FeatureCounts:

  • Counts reads overlapping genomic features
  • Uses GTF/GFF annotation
  • Handles paired-end and stranded data
  • Outputs count matrix (genes × samples)

Salmon:

  • Alignment-free quantification
  • Extremely fast (minutes per sample)
  • Transcript-level estimates (TPM)
  • Corrects for GC bias & sequence bias
🚀 FeatureCounts on Galaxy 🚀 Salmon on Galaxy
⚙️ Software

DESeq2 / EdgeR — Differential Expression Analysis

Statistical frameworks for identifying differentially expressed genes between conditions using negative binomial models.

Run on Galaxy ↗
⚙️ Software (R/Bioconductor) — Run via Galaxy

DESeq2:

  • Shrinkage estimation for dispersion & fold changes
  • Handles small sample sizes
  • Produces MA plots, Volcano plots, PCA
  • Best for < 20 samples per group

EdgeR:

  • Exact test for overdispersed counts
  • GLM-based analysis
  • Good for experiments with few replicates
  • Robust to outlier samples
